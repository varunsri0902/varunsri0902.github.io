1. Visualizing Training and Sampling

1.1 Constructing Noisy Training Inputs

The first step is to create our training inputs by interpolating between a noisy image and the final image at different times using the equation: \[ x_t = t \times x_1 + (1 - t) \times \epsilon \] 

                def interpolate(image, noise, t):
                    return t * image + (1 - t) * noise

1.2 Classical Denoising

A naive approach to denoising is to simply divide the image by it's t value. to extract \( x_1 \). However, this would give us \( \frac{x_t}{t} = x_1 + \frac{(1-t)}{t} \epsilon \), drastically amplifying the noise. To help mitigate this, we can apply a low-pass filter using a Gaussian blur. 1.3 One-Step Denoising

A better approach is to use flow matching. We can use the provided predict_velocity(x,t,condition) function to implement a one-step image update: \[ x̂_1 = x_t + (1 - t) \times v_{\theta}(x_t, t, c) \] 

                def one_step_denoise(x, t, condition, predict_velocity):
                    return x + (1-t) * predict_velocity(x, t, condition)
As seen in the examples below, these produce much better results compared to the naive approach used previously. However, there is still some detail missing, which is more obvious when starting from lower t values.

1.5 Iterative Denoising with Euler Sampling

Rather than taking one large step, we can take multiple smaller steps to reduce the error. 

                def euler_sample(x_start, t_start, step_size, velocity):
                    x = x_start.detach()
                    t = t_start
                    trajectory = [(t, x)]
                    
                    while t < 1.0:
                        dt = min(step_size, 1.0 - t)        
                        x = (x + dt * velocity(x, t)).detach()
                        t = t + dt
                        
                        trajectory.append((t, x))
                        
                    return x, trajectory
Looking at the final results of all of these approaches, it's evident that an iterative approach is the best method for flow matching

2. Conditional Generation and Guidance

2.1 Classifier-Free Guidance (CFG)

To improve the generated images as compared to 1.6, we can use CFG, which uses the difference between the conditional and null-conditional update steps to better align the image output to the prompt. The formula for this is: \[ v_{cfg} = v_c + w(v_c - v_u) \], where \( v_c \) is the conditional velocity, \( v_u \) is the null conditional velocity, and \(w\) is some weight. 

                def cfg_velocity(x, t, condition, w, predict_velocity, null_condition=''):
                    v_c = predict_velocity(x, t, condition)
                    v_u = predict_velocity(x, t, null_condition)
                    return v_c + w * (v_c - v_u)
As seen below, the quality of the output increases significantly, but the variety of output shrinks

3. Creative Applications

3.1 Image-to-Image Editing

To edit an image, we add some noise to the image until we reach a start time \(t_start \). From this, we use Euler sampling to return back to \(t = 1 \). As the value of \( t_start \) decreases, the more information is 'lost' from the image, meaning the final result will be more significant changes as compared to a greater value of \(t\). 

                def edit(image, noise, t_start, condition, predict_velocity, w=7, step_size=0.02):
                    x_start = interpolate(image, noise, t_start)
                    velocity_fn = lambda x, t: cfg_velocity(x, t, condition, w, predict_velocity)
                    final_image, trajectory = euler_sample(x_start, t_start, step_size, velocity_fn)
                    return final_image

3.3 Visual Anagrams

Using iterative Euler sampling, we can generate visual anagrams using a simple algorithm. The update for the first prompt is calculated normally as \( v_1 = CFG(x_t, t, c_a) \). The update the the second prompt is applied to the image after it has been rotated 180 degrees, and is then rotated back. Mathematically, this is \( v_2 = flip( CFG(flip(x_t), t, c_b) ) \). Finally, these are averaged then applied as a step. 

                def visual_anagrams(noise, condition_a, condition_b, predict_velocity, w=7, step_size=0.02):
                    velocity_fn = lambda x,t: (cfg_velocity(x, t, condition_a, w, predict_velocity) 
                                        + rotate180(cfg_velocity(rotate180(x), t, condition_b, w, predict_velocity))) / 2
                    t_start = 0.0

                    final_image, _ = euler_sample(noise, t_start, step_size, velocity_fn)
                    return final_image

3.4 Hybrid Images

To make hybrid images, we can either combine existing images, as we did in Project 2, or generate them by combining update velocities. Given two prompts, \( c_a \) and \(c_b\), we can generate two update velocities, \( v_1 = CFG(x_t, t, c_a) \) and \( v_2 = CFG(x_t, t, c_b) \). We can combine them into a final update using \(v = lowpass(v_1) + highpass(v_2)\) 

                def make_hybrids(noise, condition_a, condition_b, predict_velocity, w=7, step_size=0.02):
                    def velocity_fn(x, t):
                        v1 = lowpass(cfg_velocity(x, t, condition_a, w, predict_velocity))
                        v_b = cfg_velocity(x, t, condition_b, w, predict_velocity)
                        v2 = v_b - lowpass(v_b)

                        return v1 + v2
                
                    t_start = 0.0

                    final_image, _ = euler_sample(noise, t_start, step_size, velocity_fn)
                    return final_image
